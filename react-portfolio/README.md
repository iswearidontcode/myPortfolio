# React Portfolio

A standalone React portfolio website built with Vite.

## Run locally

1. Extract this ZIP.
2. Open the extracted `react-portfolio` folder in WebStorm or VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Customize your information

Your uploaded profile photo is already included at `public/profile.jpg`. To change it later, replace that image while keeping the same filename.\n\nOpen `src/App.jsx` and replace:
- `[Your Name]`
- `[Your Location]`
- `[Your University]`
- `your.email@example.com`
- `yourusername` in the GitHub and LinkedIn links
- The sample project titles, descriptions, and technology tags

The portfolio is a separate React app. It does not modify or interfere with your existing `my-nextjs-app` To-Do project.
